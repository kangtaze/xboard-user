## 🔧 关键概念

### Provider 注册流程
1. 创建 `app/XboardFerrari/Providers/XxxProvider.php`
2. 在 `composer.json` 添加 `"XboardFerrari\\": "app/XboardFerrari/"`
3. 在 `config/app.php` providers 数组插入 `XboardFerrari\Providers\XxxProvider::class`
4. `composer dump-autoload` + `php artisan octane:reload`
5. 缺任何一步 → 类找不到错误

### Hook 注册流程
1. 在 Provider 的 `boot()` 中调用：
   ```php
   HookManager::registerFilter('client.subscribe.servers', function ($servers, $user, $request) {
       // 返回修改后的 $servers
   }, priority: 10);
   ```
2. Hook 列表见 [[xboard-architecture-overview]]

### 数据库修改
1. 创建 migration：`php artisan make:migration add_xxx`
2. 运行迁移：`docker exec xboard php artisan migrate`
3. SQLite 文件位置：`/www/.docker/.data/database.sqlite`

### 邮件模板
- 模板存于 `v2_mail_template` 表（`slug` 唯一）
- 用 Blade 语法 `{{ $user->email }}` 等
- 渲染命令：`php artisan send:remind-mail` 等
